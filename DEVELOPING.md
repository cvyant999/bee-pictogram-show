# Developing the BEE Pictogram Show

Tokyo-2020-style pictogram skit for the BEE 청년부 talent show (Gospel of John). Two parts:

## 1. `show/`: the live web app
Live: https://cvyant999.github.io/bee-pictogram-show/show/
- `show/template.html` is the SOURCE. `show/index.html` is GENERATED by `skit/build.py`, which injects the slide list as `__SLIDES__`. Edit the template, then rebuild. Never hand-edit index.html.
- `show/p/*.jpg` pictograms, `show/intro.jpg` intro (cast entering), `show/bgm.mp3` music (4:49).
- Two-screen mode: the laptop page is the presenter (the actors' view: current scene, NEXT scene with pose text, countdown bar) and plays the music. "① 관객 화면 열기" opens `?view=audience` (the TV window). The windows sync via `BroadcastChannel('bee-pictogram-show')`.
- Timing follows the audio clock (`A.currentTime + SYNC`): `DING[k] = 16 + 4k` with `DING[24]=110, DING[25]=114, DING[26]=118` (short 1:48→1:50 gap). Scene k is acted from DING[k] and completes at DING[k+1]: it pulses, then after `GAP=0.35`s the next scene appears. After the last ding comes 아멘. Fade `124→140`. `SYNC` (default 0.15s, `[`/`]` adjust, saved in localStorage) shifts slides ahead of the audio.
- All images are preloaded and decoded into one `<img>` each before Start is enabled. The mp3 is fetched as a blob.
- Keys: Space pause · ←/→ scene · Esc menu · M mute (presenter); F or click for fullscreen (TV).
- `window.__step()` is a test hook: it runs one tick without rAF, for headless testing.

## 2. `skit/`: scene spec, image generation, review PDF
- `spec.py`: `C` holds the 26 clicks as `(id, English image prompt, Korean title, Korean pose, Korean staff action, [reference images in ref/])`. `PROPS` is the props table (a blank status means not ready).
- `gen.py [ids...]` regenerates pictograms (`p…`) and storyboards (`s…`) via OpenRouter (Gemini image models). It sends 정솔's feedback pages and the prop photos in `ref/` as references. Needs `OPENROUTER_API_KEY`. Examples: `python3 gen.py 03a` (both images), `python3 gen.py p03a s12b`.
- `build.py` resizes images into `img/` and writes `review_v7.html`, `BEE-skit-v7-review.pdf` (needs Google Chrome at the macOS path) and `BEE-skit-v7-overview.jpg`. It also copies the pictograms to `../show/p/` and regenerates `../show/index.html` from the template.
- Needs ImageMagick (`magick`). Python stdlib only.

## Offline backup
Download `BEE-pictogram-show-offline.zip` (or the `show/` folder), unzip, and double-click `start-offline.command` (Mac). It serves the show at http://localhost:8765/ with no internet needed. Allow pop-ups for localhost.

## Workflow
```
cd skit && python3 build.py           # after editing spec.py or show/template.html
cd .. && python3 -m http.server 8000  # open http://localhost:8000/show/
git add -A && git commit -m "..." && git push   # Pages redeploys in about a minute
```
Wording: the stagehand is "스태프" (one person). Scene 1 uses purple colouring (보라색 색소) and a clear jug.
